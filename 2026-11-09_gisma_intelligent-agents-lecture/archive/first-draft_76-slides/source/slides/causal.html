Two Different Causal Questions

[Murphy 2023, Ch. 36, from p. 1171]

67

Inside the task

Can the agent reason about causes?

“The plan failed because the museum is closed on Mondays. Moving it to Tuesday will fix it.”

Out in the world

Does deploying the agent change outcomes?

Satisfaction, time saved, error rates, compared with not having the agent.

An agent can reason well and still not help. Or the reverse.

Causal reasoning by an agent and the causal effect of deploying an agent are entirely different questions. Good reasoning inside the task says nothing about whether deployment improves outcomes.
