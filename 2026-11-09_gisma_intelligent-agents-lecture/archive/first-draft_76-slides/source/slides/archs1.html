Classical Agent Architectures

[Part 1 · Classical architectures]

10

Simple reflex agents

Fixed condition–action rules on the current input only

“If the user says ‘cheap’, show hostels.” No memory

Model-based reflex agents

Keep an internal state about what they can’t see now

Remember the user said “vegetarian” three messages ago

Goal-based agents

Have an explicit goal and plan steps to reach it

Ask: “What will happen if I do this?”

+ Rules

React to what is in front of you

+ Memory

Track what you can no longer see

+ Goals and planning

Look ahead to reach a target

Classical AI describes a ladder of agent designs; each step adds one capability. Reflex agents only react. Model-based agents keep state. Goal-based agents plan toward an explicit goal. PML2 does not cover this taxonomy; its formal model of agents is §34.5.
