Hallucination and Overclaiming

[Part 4 · Failures to verify]

51

Hallucination

Fluent but false: prices, opening hours, sources

Overclaiming

More confidence than the evidence supports

Phantom actions

“I have booked your hotel” when nothing was booked

Dangerous: agent actions have real consequences

Defence

Check the actual tool result, not the model’s story about it

“Done! I’ve booked Hotel Alfama for 3 nights.” ✓

What the logs say

booking_api.calls = 0

reservation_id = null

status = NOT BOOKED

Trust the log, not the message.

LLMs can state false things fluently, express unjustified confidence, and report actions as completed when they were not. For agents the last is the most dangerous. Always verify by checking the actual result of the tool call.
