Tools observe and act

Observe: search, prices, maps, weather

Act: send messages, write files, book

A tool call is only a proposal

The model writes a structured request; the system runs it

Check permissions; validate inputs and results

Skills and memory

Skills: packaged know-how, loaded when needed

Working memory: this task only

Long-term memory: across sessions, with privacy care

Tools let the agent observe and act. The model outputs a structured request; the system decides whether to run it. Skills package know-how; working memory holds task state; long-term memory persists across sessions and should be enabled deliberately.
