Divide the work among specialists

Specialists: research, budget, planning, evaluation

A supervisor delegates and combines results

Agents talk, and may disagree

They exchange structured messages

Conflicting conclusions must be resolved

More agents ≠ better

More calls, latency, cost, coordination

Same underlying model → shared blind spots

Add an agent only when it earns its cost.

A multi-agent system splits work among specialised agents coordinated by a supervisor. Each extra agent adds model calls, latency, cost and coordination overhead, and agents on the same model can agree with each other’s mistakes.
