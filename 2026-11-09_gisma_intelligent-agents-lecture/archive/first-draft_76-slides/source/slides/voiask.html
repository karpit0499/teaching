When Should an Agent Ask?

[Murphy 2023, §34.2.3, pp. 1101–1102]

24

Asking the human is information gathering

Same rule: ask only if the answer could change the plan

Never asking and always asking both fail

In theory: compute each question’s value

Needs confidence that matches reality

In practice: LLMs are poorly calibrated

Stated confidence ≠ how often they are right

So designers turn the principle into rules

Rule 1: always ask when a hard constraint is ambiguous.

Rule 2: always ask before an irreversible action.

Open research problem

Closing the gap between the ideal value-of-information rule and what poorly calibrated models can actually compute.

A good human travel agent asks whether 600 € is a hard limit, because the answer could change the plan, and never asks your shoe size. In theory an agent could compute this exactly; in practice LLM confidence is poorly calibrated, so designers write rules.
