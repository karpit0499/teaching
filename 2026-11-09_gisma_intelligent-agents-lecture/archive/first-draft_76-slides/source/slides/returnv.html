Short-Term vs Long-Term Reward

[Murphy 2023, §34.5.3–34.5.5, pp. 1117–1119]

39

The return: total reward over time

Not just the next step

Future rewards are often discounted a little

Greedy agents only see the next step

The 6 a.m. flight saves 40 € today…

…and costs the traveller most of day one

Value function

“How good is this state, counting all that follows?”

Compare situations by long-term prospects

06:00 flight

+40 € now

Exhausted, day one lost

Total return: worse

10:30 flight

−40 € now

Fresh for day one

Total return: better

In an MDP the agent cares about the return: the total, often discounted, reward over time. A greedy agent books the cheap 6 a.m. flight; an agent that considers the return does not. A value function estimates how good it is to be in a state considering everything that can follow.
