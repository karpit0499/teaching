MCP: Model Context Protocol (2024)

Standard way to connect an agent to tools and data

A tool exposes an MCP server; any MCP agent can use it

A2A: Agent2Agent (2025)

Standard way for agents to talk to and delegate to agents

Even across companies and frameworks

Complementary, not competing
