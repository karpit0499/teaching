When today’s action changes tomorrow

A hotel in Belém changes every later travel time

Five ingredients

States: where, when, budget left

Actions: what the agent can do in each state

Transitions: what happens next, with probabilities

Rewards: how good each step is

The Markov property

The current state holds all that matters from the past

State: Day 1, Alfama, 410 € left

Action: take tram 28

80%: arrive 10:00

20%: tram late, 10:40

Transition probabilities (illustrative)

An MDP has states, actions, transition probabilities and rewards, plus the Markov property: you need only the current state, not the full history, to decide what to do next.
