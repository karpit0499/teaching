A Bit of Agent History

[Part 1 · Same loop, new decision engine]

13

1950s–80s

Rules and logic

Shakey and STRIPS, expert systems like MYCIN

Transparent, but brittle

1990s

Rational agents

Expected utility, belief-desire-intention agents

Model uncertainty explicitly

1990s–2010s

Learning from reward

TD-Gammon, DQN on Atari, AlphaGo

Superhuman when the reward is clear

2022 →

LLM agents

ReAct, tool calling, MCP, A2A, coding agents

Broad, but weak at checking themselves

The newest era didn’t replace the old ideas. It needs them.

Each era kept the same perceive-decide-act loop and changed how decisions were made: hand-written rules, then expected utility, then learning from reward, now LLMs proposing actions from context. Uncertainty, utility and learning from reward are exactly what decide whether today’s LLM agents behave well.
