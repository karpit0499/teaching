Step 2: Give It a Tool

[Part 2 · Build step 2 of 7]

12

Attach a Code Tool to the Planner

Name it search_travel_data

It returns matching items from the fixed dataset

Write a precise description

The model decides when to call it from this text alone

Why

Observation through tools, not memory: no invented prices

Tool description

Returns hotels, museums,

restaurants and tours with prices.

Input: a type, such as

"hotel" or "museum".

In the execution log

search_travel_data("hotel")
→ 3 hotels, each with a price

Checkpoint: the log shows the tool call, its input and its result.

If the tool is never called, the description is usually too vague, or the model is weak at tool use.
