Add a Code node

Mode: Run Once for Each Item

It computes, the LLM doesn’t

Total = hotel × nights + every item

Valid only if within the budget and nothing before 10:00

Why

Hard constraints: checked exactly, never “weighed”

Code node

const plan = $input.item.json.output;

const budget = plan.budget;

const items = plan.days

  .flatMap(d => d.items);

const total = plan.hotel.price_per_night

  * plan.hotel.nights

  + items.reduce((s, i) => s + i.price, 0);

const early = items

  .filter(i => i.start < '10:00');

return { json: { plan, total,

  overrun: Math.max(0, total - budget),

  valid: total <= budget

    && early.length === 0 } };

Checkpoint: an expensive plan shows valid: false and the overrun in €.

The most important node in the workflow: a hard constraint enforced by code, exactly as in Session 1.
