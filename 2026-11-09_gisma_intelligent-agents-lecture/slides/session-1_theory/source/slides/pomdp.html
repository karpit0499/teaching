An Agent Acts on Beliefs

POMDP elementIn a coding agent
True stateWhat the bug really is, what the user truly wants
ObservationThe issue text, test output, error logs
Belief“Probably the date parser; maybe the time zone code”
ActionRead files, run tests, edit, ask, stop
RewardTests pass and the user is happy, minus time, cost and risk
PolicyThe LLM plus its workflow code

Context + memory = belief

·

LLM + workflow = policy

Formally, an agent acts in a partially observed Markov decision process, a POMDP. It never sees the true state; it maintains a belief. For an LLM agent, the context window and memory are the belief, and the LLM plus its workflow is the policy. Everything that follows is about how that policy should choose.
