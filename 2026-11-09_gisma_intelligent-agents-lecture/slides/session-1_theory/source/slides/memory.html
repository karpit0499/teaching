Remembering Is Not Learning

[Murphy 2023, §19.7,
pp. 750–755]

31

“The agent learned.” Three very different things can change.

Memory

The sticky note

“User prefers Python” is saved and read next time.

Model unchanged

Workflow

The recipe book

A designer adds a rule: always run the tests before committing.

Model unchanged

Weights

The chef goes to school

The model is fine-tuned on thousands of reviewed code changes.

Model changed

When an assistant “remembers you”, it usually wrote a sticky note.

Three different things can change when people say an agent learned. Only the third changes the model. During an agent run the weights are fixed, so LLM agents are not automatically reinforcement-learning agents. Continual learning, getting better on the job without forgetting, is still an open problem: PML2 §19.7.
