The LLM is the decision-maker

Reads its context: task, chat, tool results, notes

Proposes one action: answer, call a tool, delegate, ask, stop

The system executes it

Adds the result to the context, asks again

Reason, act, observe, repeat

Interleaving reasoning and actions (ReAct)

The basic pattern of modern agents

A trace (illustrative)

Thought: first, see what fails.

Action: run_tests("test_dates.py")

Observe: 3 failed: wrong time zone

Thought: the parser drops UTC offsets.

Action: edit_file("dates.py")

Action: run_tests()

Observe: all 12 tests pass

Thought: done. Summarise the fix.

One loop: reason, act, observe, until the goal is met or a stop rule fires.

In an LLM agent the model reads its context and proposes the next action. The system executes it, appends the result and asks the model again. Interleaving reasoning with actions is the basic pattern.
