Set Up n8n Community Edition

[Take-home · setup 1 of 2, about 15 minutes]

36

1

Install Docker Desktop

From docker.com (Windows, macOS, Linux). Start it before step 2.

2

Create a volume for your work

docker volume create n8n_data keeps your workflows when n8n restarts.

3

Start n8n

Paste the command on the right into a terminal. Leave that window open.

4

Open http://localhost:5678

Create the owner account: an email and a password. It stays on your laptop.

5

Optional: a free licence key

Free registration unlocks folders and editor debugging.

Terminal

# step 2: once

docker volume create n8n_data

 

# step 3: start n8n

docker run -it --rm --name n8n \

  -p 5678:5678 \

  -e GENERIC_TIMEZONE="Europe/Berlin" \

  -e TZ="Europe/Berlin" \

  -v n8n_data:/home/node/.n8n \

  n8nio/n8n

 

# no Docker? Node.js 20.19 to 24:

npx n8n

Community Edition is the free, self-hosted n8n. No cloud account, no trial.

Community Edition is the free edition of self-hosted n8n: it runs on the student’s own laptop with no licence key. Docker is the route n8n recommends; npx needs Node.js 20.19 to 24. The volume keeps workflows and credentials between restarts. Registering the Community Edition with an email is optional and free; it unlocks folders, debug in editor and custom execution data. Source: docs.n8n.io (installation, Community Edition features).
